## 🚀 프로젝트 개요 (Overview)

달빛 연구소(`dalbitai.com`)는 6년간의 오프라인 카페 자영업 경험과 야간 대리운전 현장의 치열한 삶의 서사, 그리고 낮 시간 AI SaaS를 직접 코딩하고 검증한 개발자의 진정성 있는 6대 자체 솔루션을 통합 제공하는 공식 랜딩페이지 및 웹 포털입니다.

## 📦 기술 스택 및 로컬 실행

- **Core**: Vanilla Modern Web (Semantic HTML5, CSS3 Custom Properties, Vanilla ES6+ Modules)
- **Tooling**: Vite 6
- **Typography**: Space Grotesk, Pretendard, JetBrains Mono

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행
npm run dev

# 프로덕션 번들 빌드
npm run build
```
